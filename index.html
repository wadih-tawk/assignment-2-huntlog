Keep your bug bounty notes in one place

HuntLog is a simple notebook for bug bounty hunters. Save the scope of each program, write notes while you test, and turn them into a report when you find a bug.

Join the beta See features

Features

Everything you need while hunting, and nothing you don't.

Scope list

Paste a program's scope once. HuntLog shows which targets are in scope and which are not.

Quick notes

Write a note in seconds and tag it, so you can find it again later.

Report drafts

Turn your notes into a report draft with the steps already written down.

How it works

Three steps, the same for every program.

  1. Add the program and paste its scope.
  2. Take notes while you test the targets.
  3. Turn your notes into a report and submit it.
